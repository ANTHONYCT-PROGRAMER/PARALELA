[Pregunta] ¿Cuál es la diferencia exacta entre un hilo y un proceso?

Respuesta: Un hilo es la unidad mínima de ejecución dentro de un proceso y comparte el espacio de memoria y variables con otros hilos (muy liviano). Un proceso tiene su propio espacio de memoria aislado por el SO y requiere mecanismos de IPC para comunicarse (más robusto pero más pesado).

[Pregunta] ¿Por qué no se puede lograr Speedup infinito agregando miles de CPUs?

Respuesta: Por la Ley de Amdahl. Todo programa tiene una fracción intrínsecamente secuencial $(1-f)$ que no se puede paralelizar (inicialización, E/S, sincronización). Cuando $p \to \infty$, el Speedup máximo queda estancado en $\frac{1}{1-f}$.

[Pregunta] ¿Qué es el GIL de Python y por qué existe?

Respuesta: El Global Interpreter Lock es un cerrojo mutex en CPython que previene que múltiples hilos nativos ejecuten bytecode Python al mismo tiempo para proteger la gestión de memoria (reference counting). Por eso, para paralelismo real de CPU se usa multiprocessing.
